# RALLY 11 — POWER SWING v6

iPhone Safari / PCで遊べるブラウザ卓球ゲーム。v5 DISTANCE RALLYをベースにした更新版です。

## v6の変更点
- ラケットを**前（画面上方向）へ素早くスワイプ**すると、球速が最大約2倍になるパワーショット
- ゆっくり前へ動かした場合は控えめ、速いスイングほど強く飛ぶ
- 左右フリックによるコースと横回転、上下回転を維持
- 下へドラッグで後退し、台から離れたラリーが可能。カメラ自動追尾も維持
- パワーショット時に `POWER ×1.x〜2.0` と表示し、強い打球音と軌跡の色で演出

## 操作
- 上へ**速く**フリック：強打＋上回転
- 上へゆっくり動かす：台に近づく＋通常の球速
- 下へドラッグ：台から下がる（下へ速く動かすと下回転）
- 左右フリック：打球コースと横回転を調整
- プレーヤーの打点にボールが来たときのスイング速度で強さを判定。
