# RALLY 11 — STYLE SHOCK Ver.13

iPhone Safari / PCのブラウザで遊べる卓球ゲームです（HTML / CSS / JavaScript）。

## Ver.13の変更
- **遠近感を強調**：奥側を細く、手前側を広く描画。低い視点を維持しネットを遠く感じるよう調整。
- **ドライブマン**：速いドライブ中心。時々、高速で低い軌道のスマッシュ。
- **カットマン**：強い下回転がかかった、ふんわり高いカットボール中心。ツッツキも使用。
- **後陣カメラ**：プレイヤーまたはCPUが大きく後退するとズームアウトし、卓球台と選手の距離感を保つ。
- **強打時の効果音**：ドライブは「シュッ・パコン」、スマッシュは強い「バコン」。端末内のWeb Audio APIで生成し、外部音声の読込なし。
- 11点制、左右のフリック、前後移動、ラリーの緩急、オーバーミスなどは維持。

## 操作
- 指を左右に動かす：ラケットの位置 / コース
- 上下へゆっくり：前進・後退
- 打球直前に上へ素早くフリック：ドライブ。非常に強いフリックならスマッシュ
- 打球直前に下へ短くスワイプ：ツッツキ
- メニューでCPUのカットマン／ドライブマン、難易度を選択

## GitHub Pagesに公開・更新
ZIPを展開し、`index.html`、`sw.js`、`manifest.webmanifest`、`icon-180.png`、`icon-192.png`、`icon-512.png`、`README.md`を**既存リポジトリのルート**にアップロード。main / (root)のGitHub Pages設定なら自動更新。

## 注意
挙動とスピンはゲーム向けの簡易物理モデルです。iPhone実機の感触は未検証です。音が出るにはSafari上で画面タップが必要です。
