# RALLY 11 — DISTANCE RALLY v5

iPhone Safari / PCで動作する卓球ゲーム。既存のRALLY 11の進化版です。

## v5で追加したこと
- 相手が奥まで返球するようになり、台から後ろに下がって打ち返す遠距離ラリーが可能
- 指の上下ドラッグでラケットを前後に移動。下へドラッグ＝後退、上へドラッグ＝前進
- 左右フリックでコース、上下フリックでスピンと球の伸びを調整
- CPUラケットも後方まで移動し深い球を返球
- カメラがズームアウト＆追尾して、手前と奥の後陣が見える
- 白基調の画面、カコンというラケット打球音

## iPhoneで公開
ZIPを展開して `index.html`, `sw.js`, `manifest.webmanifest`, 画像アイコンを **既存GitHubリポジトリの直下** に更新アップロードします。GitHub PagesのURLは変更しなくて構いません。

## 注意
現実の卓球を完全再現する物理エンジンではなく、操作性重視のゲームモデルです。iPhone実機での確認を推奨します。
