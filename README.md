# RALLY 11 — PRO CHAMPIONSHIP v18

iPhone Safari・PCで遊べるブラウザ卓球ゲーム（疑似3D）。

## 追加したプロトーナメント

- **32名参加・1セット勝負**：11点先取、10-10以降は2点差。5ラウンドで優勝。CPU同士の試合は自動進行。
- **プロCPU**：通常大会より速い返球、上／下回転と横回転の変化、左右の鋭いコースが増加。
- **ラリーの長さ**：全打球をエースにせず、鋭い球とつなぐ球を混在させ、通常大会に近いラリーの続きやすさを維持。
- **通常対戦・通常の32名トーナメントも継続**：通常大会は3ゲームマッチ（2ゲーム先取）。
- **大会の進行を個別保存**：通常大会とプロ大会をそれぞれ続きから再開可能。すでにv17で進行中の大会の保存データも引き継ぐ。
- **チャンスボール時限定のスマッシュ**、利き手選択、ドライブ／カットマン、青・赤の軌跡も継続。

## 操作と公開

SafariまたはPCブラウザでindex.htmlを開き、タイトル画面の **「🔥 プロトーナメント（1セット11点）」** を選びます。大会の対戦表が表示され、「この試合に進む」で開始します。勝てば次の対戦へ進みます。

GitHub Pagesへの更新は、ZIP内の7ファイルを既存のリポジトリ直下へアップロードしてコミットします。公開URLは変更不要です。

ゲーム向け簡易物理モデルです。iPhone実機での操作感やブラウザの効果音は使用環境により異なります。
