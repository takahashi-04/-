# RALLY 11 — CLEAR SHOTS v15

iPhone Safari / PC向け卓球ゲーム。`index.html` を開くか、GitHub Pagesで公開してください。

## 今回の変更
- 強いドライブ・スマッシュの飛距離が長すぎると、実際に奥端の外側へ着地してオーバーミスになります。強く打つほど必ずランダムでミスする仕様を変更しました。
- オーバー時は赤い×と `OUT! 台の奥` の着地点マーカー、得点画面には原因を表示します。
- 通常の弾道を低くして、打球の弧を短くしました。
- 「ツッツキ」を廃止して「カット」に統合しました。下方向へこするとカットになります。
- 弱いブロックや一部の浮いたカットは `CHANCE BALL` と表示され、山なり・遅い球になります。攻撃型CPUはチャンスボールにスマッシュを多く使います。プレイヤーもチャンス時に強く振るとスマッシュが打てます。
- 青＝ドライブ・スマッシュ、赤＝カット、灰＝ブロックの軌跡色と、利き手・前後移動・CPU戦型は維持します。

## 更新
`index.html`、`sw.js`、`manifest.webmanifest`、3つのアイコンと `README.md` を、既存GitHubリポジトリのルートにアップロードしてください。GitHub Pagesの設定は変更不要です。

## 留意事項
これは本物のラケットとボールの3D物理衝突を完全再現するものではなく、プレーしやすさを考慮した疑似3Dのゲームです。
