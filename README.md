# RALLY 11 — MATCH OPTIONS (Ver.23)

Ver.22をベースに、タイトル画面に3つのON/OFFスイッチを追加しました。

- **サイドを切る打球（初期ON）**：OFFにすると、自分もCPUも台内で弾んだあとサイドへ逃げる特殊な打球を使いません。通常の左右への打ち分けは有効です。
- **ラケットアシスト（初期OFF）**：ONにすると、飛んでくるボールが近い場合にラケットが返球位置へ少しだけ寄り、当たり判定も広がります。OFFはVer.22と同じ完全手動です。
- **オーバーミスアシスト（初期OFF）**：ONにすると、プレイヤーの強打の飛距離を抑えてオーバーしにくくします。最大級の強振ではオーバーすることもあります。

変更はその場でローカルストレージに保存され、同じ端末・ブラウザの再起動後も保持されます。外部送信はしません。

そのほかはVer.22のプロトーナメント・通常大会・カット／ドライブ・11点1セット制を維持します。
