# RALLY 11 — OPPONENT SELECT (Ver.26)

## 更新点

- **通常対戦**のCPU難易度に **プロ** を追加。イージー／ノーマル／ハード／プロから選べます。プロはプロ大会と同じ強さのCPUです。
- **通常対戦**でドライブマン／カットマンを直接選択できるように変更。選んだ戦型で試合を開始します。
- **スタンダード大会・プロ大会**は、新規作成時に各CPU選手の戦型を**ドライブマン80%／カットマン20%の確率で独立抽選**します。大会途中で選手の戦型は変更されません。抽選なので毎大会の比率が必ず80:20になるわけではありません。
- 既存大会の進行状況は保持します。過去に作成した大会の戦型を新しい確率で抽選し直すことはありません。新しい比率の大会を始めるには新規大会を作成してください。
- 全試合1セット11点制、サイド／ラケットアシスト／オーバーミスアシスト、プロ大会の20打目10% CPUミス率は維持。
